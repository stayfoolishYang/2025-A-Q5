# 2025 国赛 A 题 · Q5 求解（烟幕干扰弹投放策略）

## 1. 这是什么

对 2025 高教社杯 A 题 Q5（5 架无人机，每架最多 3 枚烟幕弹，对 M1/M2/M3
三枚来袭导弹实施干扰）建立几何-运动学模型并求解，输出 `result3.xlsx`。

## 2. 建模与求解约定

- 坐标系：原点 = 假目标（诱饵）；xy 水平面；z 向上，单位 m。
- 真目标：圆柱，轴过 `(0,200,0)`，半径 7 m、高 10 m。
- 目标代表点 `T = (0,200,0)`（题目给出的下底面圆心）。
- `g = 9.8 m/s²`；云团半径 10 m；起爆后有效 20 s；云团中心 3 m/s 匀速下沉。
- 导弹 300 m/s 直线飞向假目标（原点）。
- 无人机高度不变，速度 70–140 m/s，航向角（从 +x 逆时针，度），每机航向/速度一旦确定不再改。
- 每枚弹：脱离后受重力抛射；投放时刻 tau、引信延时 delta；起爆点由 tau/delta 与无人机（phi,v）决定。

**目标函数（选项 A）：** 最大化真目标被 M1/M2/M3 **同时**遮蔽的交集时长
`T_protect = ∫ 1{ 三枚导弹同时被遮蔽 } dt` 于 `[0, TMAX=67]`。

**修正要点：** 每枚弹生成时即计算它对 M1/M2/M3 三枚导弹各自的遮蔽区间；目标函数把
每个区间计入对应导弹。靠近目标（各视线汇聚）的云团会同时遮蔽多枚导弹，因此会被如实计入，
而不会被低估或错记到单一导弹。

参数说明：
- `--restarts`：多起点次数（越大越可能跳出局部最优，时间线性增加）。
- `--sw`：每个起点的坐标上升轮数。
- `--seed`：随机种子，保证可复现。
- `--res`：遮蔽区间时间分辨率（s），越小越精确、越慢。

依赖：`numpy`、`scipy`、`openpyxl`。

## 5. 当前结果（选项 A，LOCAL_DEV 证据）

*本机求解，属开发/集成证据（`LOCAL_DEV / FRAMEWORK_INTEGRATION /
production_eligible=false`），不主张生产级最优或可冻结。*

- 真目标同时遮蔽时长：**≈ 3.30 s**（窗口 `[61.5, 64.8]`）。
- 各导弹遮蔽并集：M1 13.80 s，M2 5.00 s，M3 3.35 s（瓶颈 = M3）。
- 部署（每机固定 phi,v）：
  - FY1 phi=179.4 v=123.6 → 1 枚弹，目标 M1
  - FY2 phi=253.0 v=94.1  → 1 枚弹，目标 M1
  - FY3 phi=150.2 v=114.9 → 3 枚弹，目标 M1/M1/M3
  - FY5 phi=151.0 v=132.5 → 1 枚弹，目标 M1
  - FY4 未贡献交集（距离目标过远，无法在导弹到达前机动到位）

## 6. 重要发现（写进论文/报告必须讲清）

1. **云团放在目标附近会同时遮蔽所有导弹**：三枚导弹的视线都汇聚到真目标点，所以
   靠近目标的云团可同时遮挡多枚导弹，这是几何必然。
2. **选“交集（同时遮蔽）”，数学上会聚焦到“遮住目标点”这一最简单策略**：
   - 能同时遮蔽多枚导弹的云团只可能位于目标点附近的小球区域；
   - 且因无人机 (phi,v) 固定，`v·S≈目标距离` 会把起爆时刻 S 锁定，同一架无人机
     难以靠多枚弹在时间上串起多个“近目标”云团；
   - 只有 FY3 能在导弹到达前机动到目标附近，其余机距离 11000–17800 m、速度不够，
     因此它们在“交集”意义下基本不贡献。
3. 因此选项 A 的最优解会集中到少数无人机/目标点云团，**其余无人机在“交集”指标下
   贡献有限**。若希望 5 机×3 弹都有独立贡献，更自然的指标是“各导弹遮蔽时长之和”，
   或在论文中把“单导弹遮蔽并集”作为并列指标展示。

## 7. 局限与边界

- 目标代表点取题目给出的下底面圆心 `(0,200,0)`；未对圆柱表面做多点采样（可在论文中作为增强）。
- 导弹到达诱饵后是否仍视为威胁未细化；这里保持 `[0,67]` 同时遮蔽要求（保守处理）。
- 每机固定 (phi,v)、每机至多 3 弹、同机两弹投放间隔 ≥1 s 均已考虑。
- 结果为启发式搜索，不保证全局最优；属开发/集成证据，不能支持“生产级最优”或“模型冻结”。
- 未做敏感性（g、下沉速度、云半径、速度界限、目标代表点），可在论文“敏感性分析”补齐。

# 附：深度学习 / 强化学习（PPO）求解（服务器）

如果你要用服务器跑深度学习，用 `src/drl_q5.py`。它是一个把 Q5 建成 MDP、用 PyTorch+PPO
训练的**可泛化投放策略**求解器。

## 建模/设计

- **状态**：t + 各导弹/无人机当前位置 + 各机剩余弹 + 各机当前航向/速度（~40 维）。
- **动作**（每架无人机）：
  - 开局 `config` 头：航向 8 档 × 速度 3 档（24 类）；
  - 逐时刻 `drop` 头：不投 / 3 目标 × 6 引信（19 类）。
- **奖励塑形**（稠密，利于收敛）：
  - 单步奖励 = 该时刻被遮蔽的导弹数（0–3）；
  - 另外对"某导弹首次被遮蔽"给 +2 奖励（引导覆盖进展）；
  - 评估/回合计分 = 三导弹同时遮蔽时长（选项 A）。
- **泛化**：训练时每个回合采样一组随机导弹/无人机初始位置（±15%）；评估时用题目给定 Q5 场景。

## 运行（服务器）

```bash
pip install torch numpy openpyxl
cd E:\数模\projects\CUMCM2025_A_Q5_SOLVE
python src/drl_q5.py --train --steps 60000 --seed 0      # 训练(可加大到几十万步)
python src/drl_q5.py --eval --ckpt drl_policy.pt --out results/result3_drl.xlsx
```

## 诚实说明（重要）

- Q5 动力学确定且已知，纯 RL 对"单一给定场景"通常**难超** `solver3.py` 的精确几何+最优化
  （后者在本机求得同时遮蔽 ≈3.15 s）。
- 本 DRL 的价值：训练一个**能泛化的投放策略**（对不同来袭态势自动给出部署），这是服务器上
  值得跑的深度学习任务，也适合作为论文的"泛化/方法"卖点。
- 未训练策略为随机（`--eval` 常见 0.00s），属正常；需在服务器上**充分训练并调参**（学习率、
  隐层、奖励权重、动作离散精度、训练步数）才有意义。
- `results/result3_drl.xlsx` 是 RL rollout 的部署结果（训练后才有价值）。
