## 3. 怎样编译LaTeX

需要安装带 XeLaTeX、BibTeX、ctex 和 gbt7714 的 TeX 环境。原稿已在 TeX Live 2023 下编译通过。

在解压根目录打开 PowerShell，执行：

```powershell
Set-Location B_solver/paper
New-Item -ItemType Directory -Force build | Out-Null
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
bibtex build/main
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
```

编译结果在：

```text
B_solver/paper/build/main.pdf
```

两次后续编译用于更新引用、图表编号和交叉引用。每一步若报错，先看 `build/main.log`，不要把之前生成的旧PDF当成此次成功输出。

如果提示找不到 `xelatex`，说明命令未进入 PATH。可以在 TeXstudio 中选 XeLaTeX，或使用本机可执行文件的完整路径。原开发机的示例是：

```powershell
& 'D:\texlive\2023\bin\windows\xelatex.exe' -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
```

这个D盘路径只适用于原开发机，同学电脑要替换为自己的安装路径。

如果提示找不到字体，检查以下目录是否完整：

```text
downloads/cumcm-latex-template-original-20260911/fonts/
```

交接包已经附带字体，`main.tex` 通过相对路径使用它们。保留包内目录结构即可。若提示PDF被占用，关闭正在查看的PDF，或者直接查看新生成的 `build/main.pdf`，不必强行覆盖旧文件。

## 4. 怎样合进同学自己的完整论文

将下面文件复制到完整论文主文件所在目录：

```text
q1_model.tex
q2_model.tex
figures/       ← 如已有同名目录，合并新增图片，不删除原图
```

在完整论文适当位置加入：

```tex
\input{q1_model}
\input{q2_model}
```

把 `references.bib` 中的五条文献记录合入自己的文献库，保持引用键不变；整篇论文只输出一次参考文献。

推荐使用包内 `cumcm2026.sty` 所提供的环境。若使用其他模板，需要支持 amsmath、amssymb、graphicx、booktabs、tabularx、float、array，以及正文用到的左对齐 `L` 列。后者可在没有同名定义时加入：

```tex
\newcolumntype{L}{>{\raggedright\arraybackslash}X}
```

当前 `main.tex` 是Q1/Q2章节审阅入口，不是完整比赛论文。合并时保留完整论文自己的摘要、其他问题、参考文献和附录。

## 6. 想在本地复算Q1/Q2

以下操作会真正运行本地Q1/Q2函数，不连接官方模拟器。新结果写入 `recomputed`，不覆盖原证据。需要先安装Python。

重新在**解压根目录**打开 PowerShell，执行：

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install numpy scipy
```

然后复制执行下面整段：

```powershell
@'
import json
import sys
from pathlib import Path

root = Path.cwd()
sys.path.insert(0, str(root / 'B_solver'))
from questions import solve_q1, q2_example

out = root / 'recomputed'
out.mkdir(exist_ok=True)
observations = json.loads(
    (root / 'B_solver/results/geometry_checks.json').read_text(encoding='utf-8')
)['counterexample']['observations']
q1 = solve_q1(observations)
(out / 'q1.json').write_text(json.dumps(q1, indent=2), encoding='utf-8')
q2 = q2_example(out)
print('Q1 status:', q1['status'])
print('Q1 diameter:', q1['diameter'])
print('Q1 MEC radius:', q1['mec_radius'])
print('Q2 candidates:', q2['candidate_count'])
print('Output directory:', out)
'@ | & .\.venv\Scripts\python.exe -
```

本包构造算例的参考值：Q1直径约40米、MEC半径约23.094米；Q2保留213个候选。比较时允许正常浮点尾数差异。Q2入口是固定首测点 `(0,0)`、示向度30°的算例，不是任意首测输入的完整命令行工具。

如果只想重新汇总论文中的历史对比图表，不需要重新求解：

```powershell
& .\.venv\Scripts\python.exe -m pip install matplotlib
& .\.venv\Scripts\python.exe B_solver/paper/comparison/analyze_existing.py
```

该脚本只读取保存的数据，更新 `comparison/evidence/` 和 `comparison/figures/`。要让新图进入论文，再复制：

```powershell
Copy-Item B_solver/paper/comparison/figures/01_historical_tradeoff.png B_solver/paper/figures/q2_historical_tradeoff.png
```

原 `experiments.py`、`ablations.py`、`make_figures.py` 是综合脚本，其主入口还涉及其他问题；复算这两问用上面的专用函数即可。

## 8. 修改时守住哪些定义

- 题面误差是±1°；接口几何函数的1.00500001°包含工程余量，不能混写。
- 20米是物理清除半径；19.999米是执行证书阈值。
- 保证接收不等于保证返回示向度，近距离可能返回 `near`。
- 最大采样后验直径不是连续情景的严格最坏值。
- NBV在历史算例中平均直径更小，但耗时更长；不要改写成两个指标同时更好。
- MEC就绪子集没有超距，不等于全部实例已经清除。
