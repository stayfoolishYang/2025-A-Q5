## 1. 局部收益的严格数学口径

设精确最小包围圆中心为 M、半径为 R，清除证书半径 rc = 19.999 m。允许落点集合为所有顶点的半径 rc 圆盘之交 C。

MEC 的支撑顶点存在权重 α_i ≥ 0、Σα_i = 1、Σα_i p_i = M，且所有有正权重的顶点满足 ‖p_i − M‖ = R。因此，对任何 c ∈ C，

```text
Σ α_i ‖c − p_i‖² = ‖c − M‖² + R² ≤ rc²
⇒ ‖c − M‖ ≤ sqrt(rc² − R²) ≤ rc.
```

对同一当前位置 x，NCCP 与 MEC 落点的直接移动差满足

```text
0 ≤ ‖x − M‖ − ‖x − c‖ ≤ ‖c − M‖ ≤ rc.
```

所以**单次成功多边形证书清除的当前移动段最多节约 19.999/5 = 3.9998 s**。每个源至多有一次成功证书清除；near 原位清除和光学清除没有这项直接替换收益。该结论不是整条任务轨迹的收益上界，因为下一步出发位置、调度、观测和恢复路径都可能随落点改变。

数值限定：当前 `mec()` 输出的是浮点中心的最大顶点距离再加 1e-8 m，不能直接将该半径代入更强的平方根公式作为严格逐例验收界；简单减去 1e-8 也不能自动获得精确 MEC。本文按理想精确几何陈述定理，用日志中的 `same_state_saving_m` 报告实际局部对比，不用浮点强界宣判案例违规。

两频道净增加 527.861938 s，其余频道合计减少约 29.949348 s。不能仅凭兜底次数同为 1 就认为恢复行为相同：**兜底对象从 baseline 的频道 8 换成了 NCCP 的频道 7**。

频道 7 的六次诊断前观测位置与结果相同：原点有方向，其后五个覆盖节点均无信号；最后的硬外包 MEC 半径均为 750.902888 m，记录的粒子数均为 6685。紧接着的出发落点却不同：频道 20 清除后，baseline 位于 `(9.528893, −509.349839)`，NCCP 位于 `(−0.897709, −523.921621)`。该次清除的多边形和测前位置相同，局部节约 17.893649 m，即 3.578730 s。

随后频道 7 的诊断日志为：

| 次序 | baseline 测点及结果 | NCCP 测点及结果 |
|---|---|---|
| 1 | (371.241, −511.480)，无信号 | (396.141, −614.150)，无信号 |
| 2 | (892.591, 130.903)，无信号 | (321.534, −259.355)，无信号 |
| 3 | (333.707, 118.708)，有方向 | (534.215, −93.139)，无信号 |

baseline 第三次诊断后 MEC 半径降至 **14.852303 m**，立即证书清除。NCCP 三次诊断后半径仍为 **750.902888 m**，在 390 个覆盖点中实际尝试 114 次，光学移动 **2839.894634 m**，光学耗时 **911.978927 s**。频道 8 的反向变化是：baseline 三次诊断后半径 74.064106 m，18 次光学尝试；NCCP 两次有方向诊断后半径 14.846402 m，证书清除。

因此总网格点数 36→390 不是“同一多边形受微扰跳出大量网格行”的证据；它对应不同频道、不同后验集合进入兜底。

可以确认：落点改变先发生，之后诊断测点、观测结果、后验尺度及兜底对象确实分岔；直接移动节约被频道 7 的额外搜索代价超过。尚不能断言：某一次清除落点单独造成了全部 497.912590 s 回退，或将某次诊断改回另一测点就一定恢复 baseline。未做逐落点干预重跑，未保存完整实时粒子数组供逐元素对照；诊断前粒子数量相同不等于独立验证了数组完全相同。此处提供轨迹证据，不把观测到的链条扩张为未经实验的单因素因果估计。

## 4. 如何解释 Q3 开发集整体平均减少 9.126 s/源

按每个场景的秒/源差值做等权平均，100 个 Q3 开发案例的结果为：

| 统计口径 | s/源 |
|---|---:|
| 整体任务平均改善 | 9.125780 |
| 整体任务改善的中位数 | 1.661327 |
| 候选同状态清除段节约的场景等权平均 | 1.854868 |
| 任一开发案例的同状态平均节约最大值 | 2.530708 |
| 精确几何单次成功证书清除的直接上界 | 3.999800 |

Q3 索引 46 单例对 100 例平均值贡献约 **3.991980 s/源**。仅作为敏感性描述，去掉该最大改善例后的其余 99 例平均改善仍为 **5.185656 s/源**；正式结果保留全部案例，不删除极端值。

这些数值说明 9.126 s/源不能全部归于“最后一步少走十几米”。实际同状态直接项约 1.855 s/源，大的整体收益来自落点变化后整条轨迹的改变，尤其是个别昂贵兜底的避免。两种统计之差也不能自动解释成某个独立验证的“纯间接因果效应”：同状态项是在候选自己的状态序列上逐次构造的局部对照，不是让 baseline 在固定状态下重新运行的完整消融。

Q4 最大回退展示了相同机制的另一面：每次证书落点均安全且当前段不更远，也不能保证后续多目标任务总耗时下降。最终是否接受 NCCP，应继续按冻结留出集的完整成功率、配对平均和尾部结果判定，不能用这两个事后挑选的极端案例代替留出验证。
