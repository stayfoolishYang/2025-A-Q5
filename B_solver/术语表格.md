# 术语与符号

| 中文 | 英文 | 符号 | 含义/单位 |
|---|---|---|---|
| 有界误差集合定位 | Set-membership localization | Ω | 所有与历史观测一致的位置集合 |
| 保守外包多边形 | Outer polygon | P | 包含Ω的凸多边形 |
| 示向度 | Bearing | θ | 从正东逆时针，度 |
| 误差半宽 | Error bound | δ | 理想1°，量化接口1.005° |
| 区域直径 | Diameter | D | 最大点对距离，m |
| 最小包围圆 | Minimum enclosing circle | MEC | 圆心q、半径R，m |
| 下一最佳观测点 | Next best view | NBV | 按不确定性和时间选择的测点 |
| 覆盖骨架 | Coverage backbone | S | 对全部未知源的发现保证 |
| 假设粒子 | Hypothesis particle | z | (x,y,φ,R,type)，非真实样本 |
| 无信号 | No signal | no_signal | 无源/超出半径/方向不覆盖的混合事件 |
| 虚拟时间 | Virtual time | T | 移动、测向、换频、光学、清除耗时总和，s |
| 程序运行时间 | Wall-clock runtime | t | 现实计算与通信时间，s |
| 清除比例 | Cleared fraction | f | 清除数/总源数 |
| 平均定位清除时间 | Mean time per cleared source | t̄ | 总虚拟时间/清除数，s/源 |
