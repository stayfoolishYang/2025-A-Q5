# 药材烘干问题数值求解报告

主结果：Q3固定半径烘干时间 **57.1726 h**；Q4收缩模型 **52.3814 h**。

计算条件：附录原公式、PCHIP、81节点、BE步长0.5 s、Picard容差1e-7°C和1e-9 kg/kg。四个Excel均按模板输出四位小数。

**外部边界只实测到4 h**。之后保持50.165°C、0.04986 kg/kg。结果是这一假设及一维径向模型下的预测，不是实验测得的烘干时间。

## 模型和算法

[模型推导、有限体积离散、边界假设与参考文献](../题目分析报告.md)。Q1热物性固定，Q2/Q3和Q4分别使用附录3和附录4。C是干基含水率，D中的温度使用K。

伪代码：读取附件并核对单位 → 插值当前边界和半径 → 按当前T、C更新物性 → 组装热量/水分三对角系统 → Picard迭代至收敛 → 更新几何积分及通量审计 → 若max(C)跨过0.15则二分子步 → 按规定时间及物理半径输出。

## 无量纲解释

Q3初始热Bi=hT R/k=1.035，湿Bi=hm R/D=2.836；阈值含水率、平台温度下湿Bi=19.876。后期扩散变慢，内部阻力上升，必须以全域最大值而非平均值判断完成。初始热Fourier数在1800 s时为0.652。

## CUDA实算

NVIDIA GeForce RTX 4060 Laptop GPU，PyTorch 2.7.1+cu118，FP64、8条完整Q3轨迹、21节点、dt=60 s。GPU耗时44.823 s，CPU同批量同终点耗时0.832 s。终态温度最大差3.553e-13°C、含水率最大差7.142e-12 kg/kg。

此小型一维问题CPU更快，主结果与大规模验证使用CPU。GPU采用现成batched dense solve作为可核对实现，暂未编写自定义CUDA三对角内核。GPU事件表仅线性定位、用于后端验证，不替代四个Excel的高精度CPU事件。8卡按样本分片，每卡一个独立进程；未持有远程服务器访问资料，未声称完成4090/V100或8卡实测。
