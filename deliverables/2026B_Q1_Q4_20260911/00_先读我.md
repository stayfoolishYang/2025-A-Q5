## 最快使用

先完整解压到可写目录。Python环境见`requirements-core.txt`，然后：

```text
python run.py verify
python run.py q1 --output outputs/q1_example.json
python run.py q2 --output outputs/q2_example
python run.py local --problem 3 --seed 0 --output outputs/q3_seed0.json
python run.py local --problem 4 --seed 0 --output outputs/q4_seed0
```

这些都是离线操作，输出位置必须不存在。Q1无输入时使用几何反例，不是官方实测；Q2默认是固定首测示例，不是任意首测的唯一答案。

官方演练另见`START_PRACTICE.cmd`：需要官方Windows模拟器、已登录账号；先正常关闭旧常驻程序再启动本包版本。它只接入用户在App中新开的演练，不会点击开局。**禁止正式测试。不要并行启动两个官方客户端。** 本轮只核验迁移入口，没有为交付再开官方测试。
