# Q3 主动定位失败计数修复：实现与验证

结论：D将发现扫描的no_signal从主动定位失败预算中分离，保留真实主动定位失败和方向次数阈值。在固定32场上平均耗时287.527954秒/源，比最初原版省39.126457秒/源，比上一版C再省2.992125秒/源。光学兜底总次数5→0，全部全清。

## 根因与最小实现

旧版把所有测量的无信号都累计到同一个negatives计数。发现扫描可能连续远离已知源，尚未进行主动定位便触发3次失败门限。新策略仅在localize上下文中累计no_signal；发现no_signal保留历史但不增减该计数。任意direction仍重置计数并增加n，near仍立即清除。

独立候选在上级active_failure.py，继承原TaggedSolver并只覆盖localize上下文和measure计数恢复，明确限制Q3/P3；没有复制整个求解器，没有新增阈值、重写网格或改物理模型。发布源码及默认入口保持原样，未推送GitHub。

```python
solver = ActiveFailureSolver(api, False, "P3", diagnostic=dict(CONFIG, local_order=True))
solver.discovery_route = "refresh_after_localize"
result = solver.run()
```
