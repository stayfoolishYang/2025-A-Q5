# NCCP候选：只改变取得证书后的清除落点

当前候选保持原来的MEC≤19.999 m触发条件、发现覆盖、下一测点评分、频道调度与诊断配置。默认仍去MEC圆心；配置显式增加`clearance_point: nccp`才启用新落点。

对硬外包多边形Ω，定义清除区域 C = ∩顶点v B(v,19.999)。凸多边形中任一点是顶点凸组合，由范数的凸性，只要落点到所有顶点均不超过19.999 m，就覆盖整个Ω。MEC圆心是现有证书提供的可行点。

在同一个Ω和当前位置x下，欧氏投影使当前清除移动距离最小，因此不长于前往MEC圆心的距离。二维情况下，最近点若不是x本身，就位于单圆光滑边界或至少两个不同圆的交点；枚举径向投影和圆圆交点即可。退化情形保留可行MEC圆心。

实现使用FP64构造候选，再同时核验浮点范数和输入浮点数对应的精确二进制有理数平方距离。边界舍入向外的候选向已认证MEC圆心内缩；无法认证的数值候选不使用。因数值内缩或退化回退，实际实现应称“带保守认证的最近点求解”，不能保证每次都返回理想实数投影的逐位精确表示。

**局部不劣不等于总耗时不劣。** 新清除落点会改变后续移动起点、观测位置、发现顺序乃至恢复路径。每次清除记录同一状态下去MEC与去NCCP的两种距离；完整配对实验另比较实际总时间，保留所有回退。

直接移动收益也有尺度上限。精确MEC中心M位于顶点凸包内，因此对任意可行清除点c，凸性给出||c−M||≤19.999 m。结合反三角不等式，当前这一段最多省19.999/5=3.9998秒；每源至多一次成功多边形证书清除。若整体平均改善超过4秒/源，超出的收益来自后续路径或观测变化，不能全归入最后一段的直接收益。

进一步用MEC支撑顶点的凸组合权重，可得||c−M||²+R²≤19.999²，其中R为精确MEC半径。代码返回的外包半径附加了1e−8余量，不应代入这个更强公式作为逐例验收上界。本轮记录实际直接节省，不用未经认证的理论半径反推成绩。

near观测仍在测量位置原地清除，单独统计，不作为NCCP新获得的零移动。主动定位和诊断恢复内的三处多边形证书清除都调用同一入口；调度和诊断成本估计仍采用原公式。Clearance gap 和 Jung 判据只用于离线审计，不参与实际选点。

后续按用户补充增加 `segment_entry` 独立对照：沿当前位置到 MEC 圆心的原线段，在安全区域内提前停止。理想精确几何下，它对固定同一个下一站还有两段路径不劣性质；NCCP只保证当前段最短。两者改变后续重调度时均无整局不劣保证。默认仍为 `mec_center`。

NCCP 原始配对版本为 `eb24b8c`。后续安全恢复及 segment 对照独立提交，完整测试增至95项。最初还修正两项审计兼容边界：零步诊断后的MEC导入作用域，以及阶段审计模块对未提供stage的普通客户端透明转发。原开发集200条基线动作与历史版本精确一致；后续安全补丁另做全部1424条保存轨迹回放，不把回放算成新模拟器案例。

追加 segment 实验沿用同一356个种子，只新增712次完整运行；256集合在提出该追加方案之前已查看过NCCP结果，因此不能把它称为 segment 的新独立留出。原始1424条结果保留，三方案比较清楚区分引用与新跑证据。
