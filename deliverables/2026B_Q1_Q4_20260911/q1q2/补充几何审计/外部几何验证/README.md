# NCCP 独立几何验证（2026-09-11）

## 范围

本包是独立的数学/几何试验，不是 B 题求解器补丁，没有导入原项目，
没有模拟器接口、HTTP 客户端或正式测试入口。
120 组测试是人工生成的几何状态，不是 B 题 120 个独立场景或 paired seeds。
未核验“519 种子晨检”，也未据此改变项目 Gate 状态。

文件：
- `nccp_geometry_probe.py`：有限候选 NCCP 原型、原路径最早安全入口原型及测试。
- `results.json`：逐项测试结果、参考求解器状态和两段路径反例。

Python 3.13.5 / NumPy 2.3.5 / SciPy 1.17.0（精确版本以 results.json 为准）。
执行命令：

```bash
python nccp_geometry_probe.py --out results.json
```

120 组非空几何状态均通过“输出点覆盖全部给定顶点”和
“到输出点不比到原见证点更远”的有理数复核；6 个解析/退化测试通过，
3 个无效输入被拒绝。120 组均满足直接收益上界的数值检查。

前 30 组另用 SLSQP 交叉检查：29 组成功且约束残差在检查范围内；
其距离结果与原型最大差约 1.27e-11 m。
另 1 组 SLSQP 返回 `Positive directional derivative for linesearch`，
未作为成功交叉验证；状态完整保留。

原型对最终坐标采用 Fraction 检查，这是针对**给定二进制浮点输入坐标**
和十进制半径的精确平方距离比较，不是对输入多边形外包正确性的证明，
不是连续观测保证，也不是最优解浮点构造的形式化误差证明。

## 数学边界

令非空紧凸多边形为 P，清除阈值 r=19.999，MEC 中心为 m、真实数学半径为 R。
C = intersection_j B(v_j,r)。当 C 非空时，其最近点 q 投影唯一。
固定同一 P、同一机器狗位置 x，||x-q|| <= ||x-m||。
这只证明清除此目标前的这一段移动不劣。

更强的直接收益界：

    0 <= (||x-m||-||x-q||)/5 <= sqrt(r^2-R^2)/5 <= r/5 = 3.9998 s.

证明：MEC 边界存在支持点 v_i 和非负权重 alpha_i，和为1，
sum alpha_i v_i=m，且 ||v_i-m||=R。对任意 c in C，

    sum alpha_i ||v_i-c||^2 = R^2+||c-m||^2 <= r^2.

再用三角不等式即可。R=r 时 C 只含 m，NCCP 没有直接收益。

## 两段路径反例

以 r=19.999 计，顶点为 r*(-0.5,0)、r*(0.5,0)、r*(0,0.25)，
MEC 中心 m=0，R=r/2。取 x=r*(39.5,30)，NCCP 为 q=r*(0.3,0.6)，
下一个固定位置 y=-q。

x->m 为 991.968544 m，x->q 为 979.951000 m；
但 x->m->y 为 1005.384281 m，x->q->y 为 1006.782474 m。
后一条完整两段路径更长约 1.398193 m（0.279639 s）。
全部顶点距 x 均不超过 1000 m，方位角跨度约 0.699 度；
因此这个状态也与当前一次有界测向及最小接收半径相容，但未构造完整生成历史。
因此单段最优并不证明多目标整局不劣，甚至不能证明下一站已固定的两段不劣。

## 更保守的对照

令 q_seg 是原线段 [x,m] 首次进入 C 的点。
可逐圆求线段参数可行区间交集，O(m) 构造。
对任意固定下一站 y：

    ||x-q_seg||+||q_seg-y|| <= ||x-m||+||m-y||.

这是一项保持下一站固定时的两段路径保证，不是自由重调度后的整局保证。
