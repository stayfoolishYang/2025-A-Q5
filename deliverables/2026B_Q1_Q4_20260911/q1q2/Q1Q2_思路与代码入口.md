# Q1/Q2 思路与代码入口

## 问题一

用测向误差的允许区间表示位置不确定性。每次观测生成两个半平面，求交得到凸定位区域；先区分空集、无界和有界，避免拿大方框截断结果冒充真实直径。有界多边形的直径由顶点对取得，代码用旋转卡壳计算。

以直径端点a、b为直径的圆覆盖区域，当且仅当每个顶点v满足 `(v-a)·(v-b)≤0`。边长40m正三角形是反例：直径40m，但MEC半径约23.094m，半径20m圆仍不能覆盖。安全清除使用19.999m门槛，MEC继续作为默认点；Jung给出约34.639284m与39.998m的两个直径界。

实际调用链：`questions.solve_q1` → 线性规划/`geometry.clip` → `geometry.diameter`、`geometry.mec`。默认误差为1°，默认不加入1800m圆域；共享几何角界为1.00500001°，两者不是同一入口参数。主入口的直径圆标记采用MEC浮点代理；严格Thales点积判据在独立审计脚本。`solver.py`只用于追溯执行点证书，不是Q1入口。

## 问题二

首测楔形结合目标圆域和1500m接收上界，构造位置外包多边形。要求第二测点到所有顶点均不超过1000m，形成保守的全向信号保证接收区域。实际例子在首测示向线坐标系中生成961网格点，筛至213点。

对每个候选，以顶点及顶点算术均值为目标位置代表，误差取负端点、零、正端点，计算15个预测示向情景的最大后验直径。用 `J = D_sample + λ T` 选点，其中 `T = 移动距离/5 + 5`，λ单位m/s。同频道不计换频。该算法是有限候选与有限情景评分，不是连续鲁棒全局最优。

实际调用链：`questions.q2_example` → `geometry.next_view(..., safe_only=True)` → `wedge`和`diameter`。首测点固定(0,0)、示向度30°。保证接收包含near返回，不保证一定返回示向度；评分未枚举near分支。λ=0与0.2选同点，λ=1、5依次提高对移动耗时的权重，数值见`交接辅助数据/q2_lambda_summary.csv`。

## 同学本地复现

本包没有执行以下命令。Q1/Q2入口只需Python、NumPy和SciPy；完整工程requirements还含其他问题依赖，不必为看这两问安装CUDA。下例在解压根目录运行，并将新结果写到`recomputed`，保留原始证据。

```powershell
python -m pip install numpy scipy
New-Item -ItemType Directory -Force recomputed | Out-Null
$env:PYTHONPATH = (Join-Path (Get-Location) 'B_solver')
```

Q1读取本包已有测点，可在Python中执行：

```python
import json
from pathlib import Path
from questions import solve_q1
obs = json.loads(Path('交接辅助数据/q1_observations.json').read_text(encoding='utf-8'))
result = solve_q1(obs)
Path('recomputed/q1.json').write_text(json.dumps(result, indent=2), encoding='utf-8')
```

Q2在Python中执行：

```python
from pathlib import Path
from questions import q2_example
q2_example(Path('recomputed'))
```

这两个函数不访问官方模拟器。原`questions.py`脚本主入口会覆盖`B_solver/results`中的文件，复现时优先用上述独立输出路径。

LaTeX编译请看`B_solver/paper/README.md`，以该目录为工作目录。原字体已完整附带，包内相对路径保持原样。合入同学的完整论文时使用两个`\input`章节及对应bib记录和figures目录；审阅包装本身不是完整竞赛论文。
