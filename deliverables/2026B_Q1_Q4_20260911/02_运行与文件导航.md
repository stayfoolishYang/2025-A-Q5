# 运行与文件导航

## 环境

本机已验证Python3环境、NumPy1.26.4、SciPy1.15.2；离线Q1–Q4不需要GPU。使用包根requirements-core.txt，不要直接按Q4原README安装另一NumPy版本再声称结果完全复现。官方接入需要Windows、tkinter、PowerShell UI Automation和单独安装的官方模拟器；本包不包含官方软件二进制、登录凭据、Python或TeX安装程序。

```text
python -m pip install -r requirements-core.txt
python run.py verify
```

绘图附加依赖在requirements-figures.txt；已生成的PDF、PNG、SVG无需安装Python即可看。原Q1/Q2 LaTeX模板及字体在q1q2/downloads，编译需XeLaTeX/BibTeX/ctex/gbt7714；没有重新编译并冒称最新全篇论文。

## 唯一推荐运行入口：run.py

### Q1

```text
python run.py q1 --output outputs/q1_counterexample.json
python run.py q1 --observations observations.json --output outputs/q1_custom.json
python run.py q1 --observations observations.json --arena-radius 1800 --output outputs/q1_arena.json
```

输入例：`[{"position":[0,0],"bearing_deg":30},{"position":[100,0],"bearing_deg":120}]`。角度单位度，位置单位m。默认不添加圆域；默认误差半角1度。统一入口对有界多边形直径进行全点对复核，若与旧卡尺不符则报错。MEC仍用原函数，不改安全阈值。

### Q2

```text
python run.py q2 --output outputs/q2_legacy
```

返回冻结213候选固定算例及四个lambda示例，采用口径只认lambda=.2。不覆盖results内历史文件。高级接收域搜索源码为q1q2/B_solver/q2_continuous_search.py，仅作为审计研究；其原始运行有Git HEAD记录依赖，独立ZIP无.git时不要直接运行该入口并以新结果替换默认。完整已运行证据随包提供，若要重新研发应回到原Git仓库。

### Q3/Q4 本地恢复引擎

```text
python run.py local --problem 3 --seed 0 --output outputs/q3_0.json
python run.py local --problem 4 --seed 0 --output outputs/q4_0
```

seed允许0–518，使用包内对应题目完整519场景。Q3输出含结果及动作；Q4输出含manifest、逐局结果、压缩动作、保守集合审计。没有HTTP服务或官方接口；真值只供引擎和事后审计，不输入在线策略。

需要并行时，每进程运行一个独立run.py local，使用不同输出路径；Q3/Q4隔离进程避免同名模块混用。已有完整性能测试不必为了查看结果重跑。

### 官方演练

双击START_PRACTICE.cmd，或`python run.py practice`。入口先检查是否已有practice_resident.py运行；有则拒绝重复启动，不会终止旧程序。当前机器旧常驻程序可以继续使用，切换包时先正常关闭它。

本包固定队号202627002054，端口127.0.0.1:2026。登录凭据不在包里。先打开官方App并登录，在App中选择Q3/Q4的“演练测试”。常驻观察器等待“等待机器狗进入”，再启动独立子进程；结束后核对官方源数与不同清除频道数。正式页、未知页、证据过期/会话不符均不接入。模式核对来自UI，HTTP本身不返回演练/正式模式；不能只靠mode参数。

新结果写runtime/official_latest，随包历史证据在results/official_cases，互不覆盖。常驻程序不会自动点击下一局；失败不自动重复入场。运行期间不要切换测试模式或开另一个发送器。**正式测试禁止。** 移植版仅离线核验UI解析与路径，本次未新增实机成绩。
