==================================================
五、R13-A：Strong Open-Route Solver
==================================================

目的：

回答一个最基本问题：

“NN + 3轮2-opt 到底还剩多少纯路径长度优化空间？”

不要先假定 LKH 一定有价值。

--------------------------------
A0：离线路径 gap audit
--------------------------------

从现有519场 R12 trace 中抽取所有 D1 refresh snapshot：

snapshot至少保存：

dog position p

remaining mandatory nodes S

current R12 route

current R12 route length

number of remaining nodes

对于同一：

(p,S)

计算更强路线参考值。

开放路径定义：

- 起点固定为 p；
- 必须访问 S 全部节点；
- 终点自由；
- 不要求回原点。

参考求解层次：

若 |S| 足够小：
使用 exact Held-Karp / exact DP / branch-and-bound
求真正 open-path optimum。

建议 exact 优先用于：

|S| <= 16 或 18

根据实际运行时间决定，
但阈值必须运行前冻结。

对于更大 |S|：

使用至少一种明显强于 NN+3x2opt 的 deterministic reference：

优先顺序：

1. multi-start construction
2. full 2-opt until convergence
3. relocate / Or-opt
4. swap
5. limited 3-opt
6. 若环境已有 LKH / OR-Tools，可额外作为审计参考

不要为了这个任务引入难以复现的外部二进制，
除非已有环境可直接复现。

计算：

gap =
(L_R12 - L_ref) / L_ref

统计：

mean gap
P50
P95
P99
max

以及：

如果每次都能走 reference route，
理论上最多能省多少移动秒 / source。

--------------------------------
A1：在线 StrongRoute
--------------------------------

只有当 gap audit 显示存在有意义空间时，
才实现在线候选：

route_policy = strong_open_route

推荐无新依赖实现：

- 固定起点；
- 多起始构造；
- 2-opt迭代至收敛；
- relocate / Or-opt；
- swap；
- 可选 limited 3-opt；
- 选最短开放路径。

必须 deterministic。

如果：

P95 route gap < 0.5%

并且换算成整局理论最大收益 < 1 s/source，

则：

STOP_R13A_ROUTE_SOLVER

不必跑完整大规模 end-to-end。

若有明显空间，
才进入完整paired实验。
