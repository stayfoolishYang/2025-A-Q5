# 21点连续发现覆盖证书

本目录保存本轮独立重建的整数四叉树证书。它针对同目录points21.json的21个冻结坐标，证明半径1800 m的连续源圆域在1000 m最低接收距离与所有闭半平面朝向下均存在可接收的站点。此前终审索引中的原始证书文件没有提供；本轮重新生成的统计与索引相同，并不表示取得了索引所指原文件。

使用标准Python即可复核，无第三方依赖、无网络请求。在本目录运行：

```text
python build_certificate.py
python check_certificate.py
python test_checker.py
```

第一步重新生成certificate.json和build_result.json。第二步不导入构建程序，使用不同几何判定独立检查全部叶格，生成check_result.json及binary64_check_result.json。第三步检验五种故意损坏的证书能否被拒绝，结果保存在negative_checks.json。独立复核已有证书只需第二步，不必重新运行构建程序。不要用Python的`-O`选项运行，因为检查器使用assert实施核验。

根矩形为[-1800,1800]×[-1800,1800]。路径中的0、1、2、3依次表示西南、东南、西北、东北子矩形。叶格分为源圆外和已覆盖两类。源圆外叶格以矩形到原点的最短距离严格大于1800 m判定；圆周上的点不会被排除。已覆盖叶格保存一组站点编号，编号从0开始，对应points21.json原顺序。

设叶矩形为B，其见证站点集为S_B。程序验证B的四角到S_B每一站点的距离均不超过1000 m；由圆盘凸性，整个B都位于这些站点的接收圆盘中。程序还验证B的四角均属于conv(S_B)；由凸性，B整体位于该凸包内。对任意g∈B，可写g=Σλ_s s，其中λ_s≥0、Σλ_s=1。如果某方向u使所有见证站点满足u·(s−g)<0，则相应凸组合小于0，但Σλ_s u·(s−g)=0，产生矛盾。因此至少一个站点同时满足距离不超过1000 m和u·(s−g)≥0。若站点与源重合，则适用近距离接收语义。

构建程序使用单调链凸包和边叉积判定；检查器不调用凸包算法，而是枚举见证站点对构成的全部支撑半平面，并核对矩形四角是否位于每个支撑半平面内。检查器另行用前缀树核对每个非叶结点恰有四个子结点，无缺叶、重复叶或祖先叶冲突。因此叶格共同覆盖完整根矩形。这是连续矩形充分条件证明，有限叶格不等于有限点抽样。

所有距离平方、叉积和四叉树分割判定均使用Python整数。构建程序按十进制原字符串精确缩放，未先转浮点。独立检查器先按Fraction重新解析十进制字符串，并额外把实际Python JSON读入的binary64浮点坐标转为精确二进有理数，重新核验同一组叶格和见证站点。两种坐标解释均通过，避免把十进制数学坐标与实际程序浮点坐标混同。

结论限于闭半平面u·(s−g)≥0及距离≤1000 m的接收语义。要转成策略层面的发现结论，还需要实际遍历相应站点并履行所有未清频道的测量义务。证书不证明21点最少，不证明任意在线策略都能访问全部节点，也不证明整局限时内全清或平均时间最优。它是本轮程序辅助数学验证，不应改写为此前已由参赛队完成的人工证明。
