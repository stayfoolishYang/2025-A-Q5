# Q4 写作与绘图全量交接包

本包依据用户本次提供的三份文件生成，统计对象以新提供的 **21+R12+F+CT geometry revision** 为准。仅读取、汇总和转换已有数据，没有重新运行求解器，也没有更改发布仓库。

## 先读结论

- 修订版：1000场、1000全清、1000通过原审计；平均520.3934166104秒/源，P95=678.44208101，P99=736.899291087。
- 其中931场混合源为主分析，69场全定向为压力分析。1000场整体统计是这份构造样本的描述，不代表实际部署分布。
- 191次中途清除失败发生于17场，18次兜底；最终全清不等于每次清除都成功。
- 历史A=25+R12+CT，历史B=21+R12+F+CT旧几何。修订版是同1000场的回放，不是新增独立样本。
- 正式包含3份Q4和3份Q3加密jlog；只能核验外层元数据，正式成绩、清除率、耗时及求解器版本对应关系均 **待补可读导出**。不要把模拟成绩填进正式表。
- 新包代码几何实现与此前GitHub提交不同；不因目录同名就声称该修订版已经上传。原题文件未随本轮提供，论文的正式题名与规则仍须对原题核准。

## 使用顺序

写作同学先读建模说明→统计表→正文与证据边界。画图同学先读数据字典→绘图任务单→运行08_脚本/plot_reference.py。使用图内case_id关联数据，严禁按文件遍历顺序拼接。

完整模拟原始数据均保留，未因失败或慢例删样本。用于论文提交的附件不必全部公开：原始正式日志含团队/票据元信息，协作共享用本包即可，公开图表仅使用脱敏汇总。

DATA_VERIFICATION.json记录输入manifest比对和本次数据派生检查；MANIFEST_SHA256.csv记录最终包内每个文件哈希。CRC和哈希证明传输/文件一致性，不等于新做了完整策略正确性证明。正式加密数据不可读是明确未完成项。
