# 多局演练自动接入

双击本目录START_PRACTICE_RESIDENT.cmd，只开一次常驻窗口。然后在官方模拟器里开Q3或Q4演练，倒计时结束后自动接入；完成后继续等待下一场。支持Q3/Q4来回切换，不必再逐场输命令。本程序不点击开局按钮，因此仍由用户在App选择下一局。

Q3固定D版79766ec，Q4固定R12版7228633，CPU。每局以新的子进程运行，状态不会跨局混用。源码指纹绑定已完成的519种子复测，不修改策略参数。

观察器每秒通过Windows UI Automation只读官方窗口，识别队号、问题、演练类型、等待状态和案例编号。正式页面、未知页面、未完成倒计时、已结束页面不触发入场。入场前再次读取真实界面核对。常驻进程和发送器分别有单实例锁；同一案例不自动重试。请勿在识别与运行过程中切换测试模式或用另一程序发送请求。

关闭窗口会等待当前局结束后退出；“暂停自动接入”只暂停接入下一局，不中断当前局。保持官方模拟器可读，不建议最小化模拟器；常驻窗口可以放到后台。无需Codex保持会话运行。

## 波动统计

J:/2026B_runs/official_latest/resident/REPORT.md、SUMMARY.json、cases.csv持续更新；sessions.json保存跨启动的累计场次。同目录保存每场启动控制台日志。各场完整请求日志及源码记录在J:/2026B_runs/official_latest/q问题_案例/。

按Q3/Q4分别报告接入次数、经官方源总数核实的全清次数、失败、未核实、均值、中位数、样本标准差、P95、最小、最大。运行中不计入成功样本；单场标准差为空，不写成零波动。失败或未能取得官方结束源总数的场次明确保留。不要在最后一条请求结束后立即关闭整个模拟器，给观察器几秒取得官方结束信息。

均值、分位数只针对已核实全清样本；必须和失败/未核实数量一起解释。不同官方随机场景不是同种子A/B。本轮接入验证的两场历史数据不混入常驻批次；对波动建议每题先累计至少20—30场，再看均值和尾部，不能据一两场宣称稳定。
