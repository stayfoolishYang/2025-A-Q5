# 官方演练与本地恢复案例：图表设计

目标：解释冻结Q3 D / Q4 R12在官方演练与本地恢复场景中的成绩量级、相对波动及路径成本；不将不同场景比较解释为同种子因果实验。

证据：官方固定快照Q3 30、Q4 27；本轮按源数分层、哈希预选后重跑的本地30/27；已有本地519/题作为历史背景。CPU策略和代码哈希冻结。官方真实源坐标未公开，图中只能画测量位置、成功清除位置，不能冒充真实源位置。白底、MATLAB蓝橙紫金色、等比例圆域、统一色标、PNG/PDF/SVG独立文件。
