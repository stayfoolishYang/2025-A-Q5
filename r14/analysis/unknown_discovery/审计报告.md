# Q1-U：未知频道首次发现概率审计

状态：Q1-U NOT QUALIFIED，完整 Q1 NOT QUALIFIED，Q2 BLOCKED。未知发现功能量已实现并覆盖全部 64 状态，但严格排名门槛和完整世界可用性尚未全部通过。R12 默认不变。

## 模型与实现

未知频道只允许 no_signal 历史；若出现正响应而仍被标为未知，模块直接报错。按完整有序观测位置历史分组，不预设所有频道可交换。组内复用二维积分，积分内部相同 no_signal 约束去重，不重复施加独立似然。

位置先验为半径 1800 m 圆盘上的均匀分布；源类型各 1/2，半径 U[1000,1500]，定向角均匀。类型、半径、方向按历史联合条件解析积分，得到 G_H(p) 和 G_H,q+(p)。未知频道无示向报告，不涉及角度噪声积分。

每组使用独立扰动 Sobol 点，经 r=1800*sqrt(u)、theta=2*pi*v 映射到面积均匀圆盘。每批 4096 点，每状态 3 批。L_c=mean(G_H)，J_cq=mean(G_H,q+)；源存在时的条件发现概率为 J_cq/L_c。事件定义是访问节点 q 并扫描所有未确认频道时，至少得到一次新源 direction 或 near；已知及已清除频道不计入新发现事件。

源数先验 N 在 10..16 上均匀，给定 N 时频道集合等可能。已确认 k 个指定频道后，令：

    C(z)=product_unknown_c (1+L_c*z)
    Z=sum_m [z^m]C(z)/choose(20,k+m)
    P(M=m|H)=[z^m]C(z)/(choose(20,k+m)*Z)

m 从 max(0,10-k) 到 16-k。已知源自身的历史似然在当前独立参数先验下为对所有 N 公共的因子，归一化时消去。均匀 N 的 1/7 同样消去；组合因子没有丢掉。

对节点 q，令 C_no,q(z)=product_c(1+(L_c-J_cq)*z)。P_new(q)=1-sum_m [z^m]C_no,q(z)/(choose(20,k+m)*Z)。这保留固定总数造成的频道存在性依赖，支持不同历史组，并不使用独立 Bernoulli 近似。所有未知历史相同时自然化为 sum_m P(M=m)*(1-(1-r_q)^m)。

M=1 的概率不等于 N=16 的概率，只有 k=15 等相应条件下才关联“第16源”；没有把发现事件当作整局任务终止。

## 世界构造

未知源按上述离散 M 后验抽数，再通过后缀组合动态规划抽取存在频道。位置按各组积分点的 G_H 权重抽取，随后按合法角区间/半径区间的质量抽类型、朝向和半径。未来噪声场复用原持久网格机制，未知历史不含示向噪声条件。

已知源部分完全复用原 weighted posterior sampler，不优化其参数。合成世界后使用原历史精确重放检查，并检验两个未来位置的噪声查询顺序不影响结果。有限积分点与有限已知源提案仍是近似 posterior，不宣称等于官方 hash-seed 后验。
