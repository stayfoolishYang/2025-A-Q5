# Q1：相容噪声体积与近似后验资格审计

当前状态：**Q0 = PASS（已测历史重放）；Q1 = NOT QUALIFIED；Q2 = BLOCKED BY Q1**。

本轮采用明确声明的“独立、均匀、持久网格噪声近似 belief”。不追踪或枚举官方 hash seed。不参与发现覆盖保证或 MEC 证书，不修改 R12 路径、频道调度、清除策略。没有读取 oracle continuation 成本，没有评价 advantage，没有新端到端或官方测试。

## 1. 已实现的统计修正

一次误差是四个网格值的平滑双线性插值。不同位置可能共享网格顶点，因此不能把每次示向报告的合法区间宽度独立相乘。

设全部相关网格值为 eta，先验为独立 U[-1,1]，历史报告构成联合约束 lo <= A eta <= hi。相同系数行先合并区间；不同系数行即使属于同一个 cell 也保留联合约束。报告区间按已验证的取整及物理裁剪规则反推。

对固定源状态 x，目标权重为 V_H(x)=P(lo <= A eta <= hi)。位置、朝向、半径、类型的先验提案经几何条件筛选后，使用此联合相容概率加权，而非“能构造噪声就等权”。几何条件化的归一化常数对同频道同历史的提案相同，归一化位置权重时消去；这依赖本轮明示的独立均匀源参数近似先验。

实现采用重要性采样，不使用 hit-and-run。先选线性独立约束 C，以及可逆的网格列 B；其余网格值 eta_free 按均匀先验采样，独立约束的误差 z 在对应报告区间中采样，再解：

    eta_pivot = B^{-1}(z - C_free eta_free)

每个合法样本的先验/提案密度比为：

    w = product_k((hi_k-lo_k)/2) / abs(det(B))

所有网格值仍需位于 [-1,1]，未用于变量变换的约束也必须全部满足；最终逐报告精确核验。失败样本权重为零，计算平均体积时仍计入总提案数。雅可比项是关键，不能漏掉。

在精确算术下，该体积估计为无偏重要性估计；位置与噪声联合重采样仍是有限样本的自归一化近似，不能宣称有限样本已经得到精确 posterior。位置 ESS 与条件噪声 ESS 分别记录，不能混用。提案条件还包括历史接收、near 和 clear 的几何分支，整世界再核验全部历史。

## 2. 为什么没有继续调 128 步链

直接估计联合测度并重采样，替代了原来的“给每个位置构造一条相容链”。因此这里比较的是采样量和独立位置提案，而非 MCMC 步数；不存在用 512 次独立提案冒充 512 步混合检验的情况。

先实现的逐网格顺序重要性采样在 36 次整世界构造中有 3 次总权重为零，均为状态 0653_18、频道 14。该频道有 4 条示向约束、7 个网格变量；128 个位置假设只有 1 个被报告支持直接排除，其余却都没有有效噪声样本。共享网格的窄联合区域导致逐坐标提案效率低，不能用“后验为空”解释。

保留这批失败后，改用上述联合变量变换，在相同整世界种子和采样预算下完成 36/36 历史重放。由于提案方法改变，同种子对应的潜在世界不必相同；这不是策略 A/B。没有增加预算掩盖这次退化。

## 3. 实际验证结果

解析校验覆盖单变量区间、两个独立变量区间、共享变量的两个线性约束，每类 4 个随机种子。共享例子的精确概率为 11/300，估计与解析值在预设 6 个 Monte Carlo 标准误范围内相符。重复同一条观测三次时，样本与权重逐项不变。有限算例不构成任意高维实现的完整证明。

固定提案审计：早、中、后期各 4 个状态，共 12 个；每状态选择示向历史最丰富的已知频道。固定 128 个位置参数提案，噪声样本量 128/256/512、各 3 次重复。顺序提案的最大接收概率极差约 3.51 个百分点，但固定位置提案会掩盖位置采样误差，不能据此放行。

联合变量变换的完整世界检查：12 状态 × 3 个独立种子，36/36 精确重放通过，共 378 次已知频道抽样；每频道 128 个位置提案、每位置 512 个噪声提案。位置 ESS 最低为 5.14/128；抽中位置的噪声 ESS 最低为 10/512。无重放失败不等于没有重要性退化。

独立位置提案复测：相同 12 个状态，每状态 3 批独立位置提案；每批 512 个位置参数、每位置 512 个噪声提案。所有 36 批均有非零总权重，但节点接收概率的最大批间极差为 9.72 个百分点。12 个状态中，1 个状态的 top-3 集合改变，2 个状态的 top-3 排列改变。不能把较稳定的排名替代概率校准。

这里的接收概率是“所审计已知源在候选节点的接收概率”，用于检查后验函数量；它不是“发现任意新源概率”，不是完整动作价值，也不是 deviation precision。一些源已经清除，审计函数量只作反事实测度检查。某状态函数量全零时稳定是退化事实，不算积极证据。

## 4. 为什么仍不放行 Q1

目标测度和重要性密度比已经补上，且不再把相容位置等权。但目前只有 12 个代表状态的独立位置提案检查；最小 ESS 仍低，未知频道的有限粒子近似也尚未独立检验。没有预注册的全状态稳定性通过阈值，不能事后凭 9.72 个百分点“看起来可接受”宣告 PASS。

下一步应按 ESS 分层定位薄弱频道，分别核实位置提案覆盖与未知频道粒子近似；对相同状态固定评估节点、用独立提案检验概率差异及误差。需要事先给出可接受的功能量精度和退化回退条件。未满足以前，实验 sampler 不接入价值估计器，R12 默认不变。

Q2 继续封锁。后续若放行，应使用已有 2000 个 oracle states，报告 deviation coverage—precision、错误偏离损失/CVaR 和机会捕获率，并保持同世界配对续跑。本轮没有计算这些量。
