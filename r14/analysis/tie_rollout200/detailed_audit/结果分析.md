# 112/200 状态 paired rollout：中期结果审计

结论：当前没有可部署的新策略收益证据。零偏离由置信门槛与尾部风险门槛共同造成；但放松门槛的事后比较也未显示足够可靠的价值判别。不能把本轮解释为“完整 rollout 无效”或“只差调松门槛”。

## 完成度与适用范围

计划 200 状态，完成 112：early 50、middle 50、late 12、额外 N16-late 0。6 状态有部分记录，82 尚无结果。已保存 1827 个配对世界和 8046 次分支续跑；完整状态对应 1792 个世界。部分结果不进入效果评估，不能把完成 112 个当作均衡四层样本。当前没有跑测进程，未从报告文件推断停止原因。

112 个状态共 382 个非 R12 候选。所有状态都实际完成 16 个同世界配对样本，未因候选超限或 sampling failure 自动回退；本批最终零偏离来自数值门槛。文件里的 QUALIFIED_ESTIMATE 只表示完成了估计流程，不表示价值估计器通过资格认证。

## 门控链条

| 条件 | 候选数 |
|---|---:|
| 全部被评价候选 | 382 |
| 估计平均 Delta >0 | 52 |
| 校正后 t 近似下界 >0 | 2 |
| 经验 loss CVaR90 <=0 | 0 |
| 同时通过部署门槛 | 0 |

Delta=C(R12)-C(candidate)，单位是当前状态之后完成任务的秒数，不是秒/源。

门槛代码确实要求有符号损失 -Delta 的最坏 10% 均值 <=0，不是将损失截断后再算。16 个世界时，这一尾部估计由最大损失样本与第二大损失样本的 0.6 权重组成，等效 1.6 个样本；估计很不稳定，同时要求相当强。增到 64 可以提高估计精度，但不能保证真实的正尾损失消失。

2 个通过置信下界的候选都因 CVaR 被挡：0484_01 候选14，预测均值 +442.91 s、LCB +8.75 s，而真实场景 oracle Delta=-308.46 s；0070_01 候选21，预测 +327.69 s、LCB +33.14 s，oracle +257.22 s。前者说明风险门槛确实挡住了一次坏偏离，后者说明它也会挡住好机会。只有两个例子，不能用 50% 当作稳定总体精确率。

## 候选机会仍在，价值判断并不可靠

112 状态中 56 个在当前候选集合内存在更快的 known-world oracle continuation。382 候选中 112 个 oracle Delta 为正，但其中 83 个被估计成非正均值。预测正均值的 52 个候选中，29 个 oracle 也正，候选级正预测精确率 55.77%。同状态候选相关，这不是 382 个独立样本。

预测均值与单场景 oracle Delta 的候选级 Pearson 相关约 0.315。单场景 oracle 不是精确后验期望，因此这种差异不能单独证明 posterior 均值存在系统偏差；但它直接反映当前单场景决策判别仍弱。

## 仅用于诊断的事后均值规则

如果事后去掉置信和风险门槛，每状态选估计均值最高的候选，且仅当其均值 >0 时偏离：

- 28/112 状态偏离，覆盖率 25%。
- 19 次更快、9 次更慢，精确率 67.86%，低于设想的 80%～90%。
- 9 次错误偏离平均损失 384.03 s，最大损失 702.47 s。
- 28 次偏离的平均 oracle Delta 为 +109.45 s。

最后这个正均值不能忽略，但也不能当成部署收益：它是未完成、非独立校准样本上的事后规则，每次只改一个动作、后续回 R12；多次在线改动会改变之后状态分布。不能把这些单决策收益相加或换算成整局加速率。该规则没有写回算法、没有启动新实验。

## 当前决策

保留 R12 和原门槛。不要为得到非零偏离而直接调松 CVaR。当前结论是“尚未达到高精确率价值判断”，不是“R12 数学最优”，也不是“候选没有机会”。

若继续这最后一轮，优先补齐剩余 88 状态，尤其额外 N16-late 层；它目前没有完成案例，不能据早中期主导的 112 例结束整个研究方向。16→32→64 的追加应另有冻结规则，不因为看见某个 oracle 结果而选择性加样本。若不再投入，则把这批作为未完成的负/边界证据收录，不称完整 200 状态验证。
