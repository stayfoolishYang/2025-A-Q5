# R15 Sampler Qualification Gate

状态：**NOT QUALIFIED**。R12 默认不变。未评价价值估计器，未启动新的端到端场景或任何官方测试。

## 已查明的根因

旧版完整审计覆盖 2000 个冻结状态、每状态 2 个候选世界：3583 个兼容，417 个失败（10.425%）。此前 204/2348 是中间进度，不能与最终计数并列当作两个实验。

417 个失败世界按原随机种子全部重建，并继续重放整段历史，共发现 446 条不匹配观测。全部属于 `ANGLE_ROUNDING_MISMATCH / physical_clamp_after_rounding`：旧 sampler 只反推两位小数取整区间，漏掉冻结 quantizer 的物理范围裁剪。不是放宽数值容差能解决的问题。

具体例子：状态 0725_02、世界种子 1437155、频道 16、历史动作 37。真实几何角 72.6459866644°，噪声 0.9990503196°。普通取整得到历史值 73.65°，但物理上界的百分度整数是 floor((72.6459866644+1)*100)=7364，所以冻结规则实际返回 73.64°。该位置假设不可能生成历史报告 73.65°，必须拒绝。

本批 446 条失败均为上述机制；这不证明所有可能状态中不存在其他故障。完整诊断保存历史/重放响应、源参数、角度、噪声、约束残差以及潜在网格。`results/sampler_diagnostics` 的每世界 JSON 可复现，`failed_observations.csv` 可逐条筛选。

## 修正方式与边界

保留旧 sampler、旧噪声模块和全部原始结果。新增 v2 独立模块，按照冻结规则反推可生成报告的噪声区间：先检验报告整数是否位于 ceil((base-1)*100) 至 floor((base+1)*100) 内；端点报告的原像延伸到物理噪声边界 ±1；内部报告按取整区间处理。处理 0/360° 环绕。

生成噪声场后逐条精确调用 quantize_bearing 核验，整世界再重放全部历史 accepted / measure_result / svd_deg / clear_result。不能复现就拒绝，没有扩大报告匹配容差，没有增加原 proposal 重试预算。

同一个采样种子下修正版可能接受另一个源假设。因此回归结果不是“让原来不合法的世界变合法”，而是拒绝不可实现假设后重新生成世界。新接受报告与历史必须精确相等。

## Q0 / Q1 / Q2 的资格口径

- Q0 历史响应回归：修正版 4000/4000 个世界历史响应精确匹配，0 个重放失败；完整计数见同目录 summary.json。覆盖上述固定 2000 状态的两个随机种子，不是对所有状态的全称证明。每个接受世界还检验未来两个位置查询顺序互换时噪声不变。
- 更严格的冻结模型边界：目前噪声潜变量是独立有界网格，未证明存在一个冻结 hash-noise 种子生成整个网格；相同响应分支、quantizer 和持久平滑结构不等于精确恢复冻结 seed posterior。所以只能报告这类网格世界的历史重放通过，不能报告完整冻结生成模型已经闭合。
- Q1 未通过：已知源位置均匀提案经可行性筛选后，未乘以条件噪声场的相容体积；128 步 hit-and-run 无混合收敛证据；未知源仍使用有限粒子近似。上述因素都不因零重放失败而消失。
- Q2 未执行：当前不做 Δ 排名或风险稳定性评估，不将两个世界的重放当作重采样稳定性证据。先解决 Q1 的目标分布定义和采样权重，再决定是否放行价值资格实验。

拒绝采样本身并非错误：对正确提案施加正确似然/条件，拒绝恰恰是形成目标条件分布的方式。当前风险来自错误条件、提案未按目标似然加权，以及有限迭代近似。分层拒绝率是诊断线索，不单独证明 posterior bias。

## 分层结果与统计单位

旧版世界拒绝率：早期 58/1000=5.8%；中期 102/1000=10.2%；后期 257/2000=12.85%。后期包括额外富集的 N=16 后期样本，不能当作自然任务分布。

按历史观测数：0–20 条为 3/248=1.21%；21–50 条为 9/152=5.92%；51–100 条为 29/360=8.06%；101–200 条为 143/1332=10.74%；201 条以上为 233/1908=12.21%。相关状态及同状态两次采样不独立，未以 4000 个独立场景计算显著性。

按 N、阶段、历史长度和已知源数的表格已保存。真实 N 仅作为事后审计标签，未交给 sampler。修正版源类型拒绝表的分母是“进入噪声条件化的已知源提案”，不同于整世界拒绝率，也不包含前面的几何粒子筛选。该表不能冒充完整提案分布审计。旧版未保留兼容世界的源类型，不能凭失败样本推算旧版按源类型的拒绝率。
